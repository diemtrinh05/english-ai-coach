thật và profile được lưu bằng PUT thật. Mỗi lần chạy có run UUID mới.

Android dùng production `AppSessionDependencies`, `ApiClient`, Retrofit APIs,
repositories, UseCases, ViewModel, Fragment và MainActivity. Test chỉ đọc public
ViewModel snapshot qua reflection của Fragment để đối chiếu chính request đã
được UI gửi; không sửa state hoặc kết quả. Các request race đi qua production
ApiClient và actual TLS socket đến cùng backend/database.

CA/keypair/keystore/password được sinh riêng từng host JVM trong TEMP. Password,
JWT signing secret và credential đăng ký không được in log, truyền instrumentation
arguments hoặc commit. Public certificate được truyền làm trust anchor cho
TrustManagerFactory PKIX trong instrumentation process; hostname verification
của production OkHttp giữ nguyên. Không trust-all, không sửa OS trust store,
proxy, global environment hoặc production network configuration. Test restore
Security property/provider và xóa private token state trong finally/After.

Host/device checkpoint dùng file trong cache app, chỉ chứa UUID/request/result
không có token/password. Host đọc qua `adb run-as`, chuẩn bị due fixture và kiểm
tra committed SQL trước khi release checkpoint. Không thêm HTTP control endpoint.
File handshake có deadline; race dùng latch/barrier bounded và SQL timeout20s.
Mockito spies chỉ chèn timing quanh real repository methods; không mock return
state, mutation, transaction, identity hoặc HTTP result.
